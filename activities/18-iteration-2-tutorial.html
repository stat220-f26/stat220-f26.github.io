map vs. for loops

map pros map cons
Don’t have to pre-allocate storage Hard to get used to if you learned for loops first
Don’t have to define an index Often need to define a function
Less error-prone Less fine-grained control
Takes advantage of functional programming

For this class, you’ll learn the basics of both and practice them on homework. For projects, you can use whichever approach makes more sense to you.

It may help to first write a custom function that does the right thing depending on the type of the input. (Remember is.numeric() and is.factor() from earlier.)

# Inside the function: if x is numeric, return max(x, na.rm = TRUE) - min(x, na.rm = TRUE).
# If x is a factor, return table(x). Use two if() statements with return().
summarize_depends <- function(x) { if (is.numeric(x)) return(max(x, na.rm = TRUE) - min(x, na.rm = TRUE)) if (is.factor(x)) return(table(x)) } map(penguins, summarize_depends) 
summarize_depends <- function(x) {
  if (is.numeric(x)) return(max(x, na.rm = TRUE) - min(x, na.rm = TRUE))
  if (is.factor(x)) return(table(x))
}

map(penguins, summarize_depends)

# Replace the first slice_sample() with slice_sample(n = 1, by = season),
# then add a second slice_sample(n = n) for the 20 players.
sample_finalists_2 <- function(n) { us_castaway_results |> slice_sample(n = 1, by = season) |> slice_sample(n = n) |> filter(finalist) |> count() |> pull(n) } set.seed(0217) rep(20, 1000) |> map_dbl(sample_finalists_2) |> table() / 1000 
sample_finalists_2 <- function(n) {
  us_castaway_results |>
    slice_sample(n = 1, by = season) |>
    slice_sample(n = n) |>
    filter(finalist) |>
    count() |>
    pull(n)
}

set.seed(0217)
rep(20, 1000) |>
  map_dbl(sample_finalists_2) |>
  table() / 1000

Part 6: A permutation test

Recall the unscaled_cancer data. One question we might ask: is the radius of malignant tumors noticeably different from the radius of benign tumors?

This tells us the average difference in this sample, but we don’t know whether that difference is “surprising.”

The idea

A permutation test asks: if there were no difference between the groups, how big of a difference would we see just by chance?

  1. Assume there is no difference between the groups
  2. Shuffle the group labels (benign/malignant) at random
  3. Compute the difference in the group means
  4. Repeat a bunch of times
  5. Compare the observed difference to the distribution of simulated differences

If the observed difference is much bigger than the simulated differences, we have evidence of a statistically significant result.

Your turn: run the experiment

Exercise F. Finish the function below. It should (1) create a new column class_shuffled that is a random permutation of Class (hint: see the sample() function), (2) group by class_shuffled and compute the group means, and (3) return the difference in the means. Right now class_shuffled is just a copy of Class, so the function returns the observed difference. Edit that line so the labels are shuffled.

# sample(x) returns a random shuffle of the vector x. Which column do you want to shuffle?
permute_diff <- function() { unscaled_cancer |> mutate(class_shuffled = sample(Class)) |> group_by(class_shuffled) |> summarize(mean = mean(Radius)) |> pull(mean) |> diff() } permute_diff() 
permute_diff <- function() {
  unscaled_cancer |>
    mutate(class_shuffled = sample(Class)) |>
    group_by(class_shuffled) |>
    summarize(mean = mean(Radius)) |>
    pull(mean) |>
    diff()
}

Function quick reference

Function Purpose
map(.x, .f) Apply .f to each element of .x; returns a list
map_dbl(), map_chr(), map_lgl(), map_int() Same, but returns a vector of that type
map_dfr() Same, but row-binds the results into a data frame
rep(20, 1000) A vector with 1,000 copies of 20 (something to map over)
slice_sample(n = 20) Randomly sample 20 rows
slice_sample(n = 1, by = group) Randomly sample 1 row per group
set.seed(0217) Make random results reproducible
sample(x) Randomly shuffle (permute) the vector x
table(x) / length(x) Proportion of each value of x
