[1] 1196
# Average delay of MSP flights in September
flights |>
  filter(dest == "MSP", month == 9) |>
  summarize(

  avg_dep_delay avg_arr_delay
          <dbl>         <dbl>

“Flight delay” is ambiguous. Flights to MSP in September leave about 15 minutes late on average, but arrive on time (the average arrival delay is slightly negative). Either answer is fine if the student says which one they used, and remembers na.rm = TRUE.

  1. Which of the three ids has rows in cast_info?
dbGetQuery(db, "SELECT person_id, role_id, COUNT(*) AS n

SQL chunks

The same query in a SQL chunk. Options start with --|, and connection names the R object holding the connection:

```{sql}
--| connection: db
--| output.var: filmography
SELECT title.title, title.production_year, char_name.name AS role
FROM cast_info
JOIN title ON title.id = cast_info.movie_id
JOIN char_name ON char_name.id = cast_info.person_role_id
WHERE cast_info.person_id = 2977372
  AND cast_info.role_id = 2
  AND title.kind_id = 1
ORDER BY title.production_year;
```

Common mistakes: using #| instead of --| for the options, or running the chunk before db exists.
