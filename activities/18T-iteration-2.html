Part 2: map()

The purrr package (loaded with library(tidyverse)) gives us map(), which can replace many for loops.

  • .x: what to iterate over

How does mapping work?

Suppose we have quiz 1 and quiz 2 scores for 4 students stored in a list, and we want the mean score on each quiz.

Part 5: Simulation

Iteration is especially useful for simulation. In statistics we often work with a random sample to learn about a population, and we care about the uncertainty in our results: did we find a real trend, or could it be due to sampling variability?

Example: Survivor finalists

If we randomly choose 20 previous Survivor players to play on a new season, how likely are we to get zero finalists? First, here’s one random sample of 20 players. Run it a few times:

  filter(finalist) |>
  count()

You get a different answer each time, because the sampling is random. To make results reproducible, we can set a seed. Run this chunk several times:

Part 6: A permutation test

Recall the unscaled_cancer data. One question we might ask: is the radius of malignant tumors noticeably different from the radius of benign tumors?

unscaled_cancer |>
  group_by(Class) |>
  summarize(mean = mean(Radius))

This tells us the average difference in this sample, but we don’t know whether that difference is “surprising.”

The idea

A permutation test asks: if there were no difference between the groups, how big of a difference would we see just by chance?

  1. Assume there is no difference between the groups
  2. Shuffle the group labels (benign/malignant) at random
  3. Compute the difference in the group means
  4. Repeat a bunch of times
  5. Compare the observed difference to the distribution of simulated differences

If the observed difference is much bigger than the simulated differences, we have evidence of a statistically significant result.

# The observed difference (malignant minus benign)
observed <- mean(unscaled_cancer$Radius[unscaled_cancer$Class == "M"]) - mean(unscaled_cancer$Radius[unscaled_cancer$Class == "B"])
observed

permute_diff <- function() {
  unscaled_cancer |>
    mutate(class_shuffled = sample(Class)) |>
    group_by(class_shuffled) |>
    summarize(mean = mean(Radius)) |>
    pull(mean) |>
    diff()
}

set.seed(0217)
diffs <- map_dbl(1:1000, \(i) permute_diff())

tibble(
  diffs = diffs
) |>
  ggplot(aes(x = diffs)) + 
  geom_histogram(col = "white", bins = 25) + 
  geom_vline(xintercept = observed, col = "darkred", linetype = "dashed")

# proportion of simulated differences at least as extreme as the observed one
mean(abs(diffs) >= abs(observed))

Function quick reference

Function Purpose
map(.x, .f) Apply .f to each element of .x; returns a list
map_dbl(), map_chr(), map_lgl(), map_int() Same, but returns a vector of that type
map_dfr() Same, but row-binds the results into a data frame
rep(20, 1000) A vector with 1,000 copies of 20 (something to map over)
slice_sample(n = 20) Randomly sample 20 rows
slice_sample(n = 1, by = group) Randomly sample 1 row per group
set.seed(0217) Make random results reproducible
sample(x) Randomly shuffle (permute) the vector x
table(x) / length(x) Proportion of each value of x

## How does mapping work?

Suppose we have quiz 1 and quiz 2 scores for 4 students stored in a list, and we want the mean score on each quiz.

```{webr}
quiz_scores <- list(
  quiz1 = c(80, 90, 70, 50),
  quiz2 = c(85, 83, 45, 60)
)
```

# Part 5: Simulation

Iteration is especially useful for **simulation**. In statistics we often work with a random sample to learn about a population, and we care about the *uncertainty* in our results: did we find a real trend, or could it be due to sampling variability?

# Part 6: A permutation test

Recall the `unscaled_cancer` data. One question we might ask: is the radius of malignant tumors noticeably different from the radius of benign tumors?

```{webr}
unscaled_cancer |>
  group_by(Class) |>
  summarize(mean = mean(Radius))
```

This tells us the average difference *in this sample*, but we don't know whether that difference is "surprising."

## The idea

A **permutation test** asks: if there were *no* difference between the groups, how big of a difference would we see just by chance?

1. Assume there is no difference between the groups
2. Shuffle the group labels (benign/malignant) at random
3. Compute the difference in the group means
4. Repeat a bunch of times
5. Compare the observed difference to the distribution of simulated differences

If the observed difference is much bigger than the simulated differences, we have evidence of a statistically significant result.

```{webr}
# The observed difference (malignant minus benign)
observed <- mean(unscaled_cancer$Radius[unscaled_cancer$Class == "M"]) - mean(unscaled_cancer$Radius[unscaled_cancer$Class == "B"])
observed
```
