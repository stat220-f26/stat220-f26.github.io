Large language models (LLMs) are, at their core, programs that predict the next word (or piece of a word) given the words so far. In this activity you will build a tiny version of this idea, using only tools you already know: tokenizing, counting, and a bit of dplyr. You will not need an LLM or any AI tool for this activity.

This should take about 15 to 20 minutes, and you should watch the video after trying this activity. There will be a homework problem on HW6 where you will turn in your written answers.

Suppose someone types a word and we want to guess the next one. One simple rule: pick the word that most often follows it in the reviews.

bigram_counts |>

Turn in (Part B): For "data", what are the top predicted next words? If we always picked the single most likely next word, what would go wrong when we tried to generate a whole sentence?

Step 4: Turn counts into probabilities

Counts are hard to compare across words ("the" shows up far more often than "python"). Convert them to probabilities: for each word1, what proportion of the time is it followed by each word2?

bigram_probs <- bigram_counts |>
  group_by(___) |>
  mutate(prob = n / sum(___)) |>
  ungroup()

As a check, the probabilities for any one word1 should add up to 1:

bigram_probs |>
  filter(word1 == "great") |>
  summarize(total = sum(prob))

Step 5: Generate text

Instead of always taking the most likely word, we can sample the next word at random, giving more likely words a better chance. Run this chunk a few times:

bigram_probs |>
  filter(word1 == "great") |>
  slice_sample(n = 1, weight_by = prob) |>
  pull(word2)

Now we repeat that step over and over, using each new word as the next starting point (instead of always using "great"). The function below does this for you. (Don’t worry about how it works yet; we will learn how to write functions and loops next week.)

generate_text <- function(start, n_words = 10) {
  words <- start
  for (i in seq_len(n_words)) {
    next_word <- bigram_probs |>
      filter(word1 == words[length(words)]) |>
      slice_sample(n = 1, weight_by = prob) |>
      pull(word2)
    if (length(next_word) == 0) break
    words <- c(words, next_word)
  }
  paste(words, collapse = " ")
}

generate_text("this", n_words = 12)

Run generate_text() several times, with different starting words (try "the", "i", "great", and a word of your choice). Try a starting word that you think will not be in the reviews at all.

Turn in (Part C): Paste one generated sentence that you think is the most convincing and one that is the least convincing. What does the model get right? What does it get wrong, and why do you think that happens?
